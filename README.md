# CQuick 战队 · 电控组招新考核仓库

欢迎来到 **CQuick 战队电控组** 招新考核！本仓库用于电控组新生的分周考核成果提交。

## 这是什么

- 这是电控组招新的**考核提交仓库**，按周分目录。
- 每周会有一个对应的考核任务（从 ROS2 环境搭建开始），你需要在**对应周的目录**下提交你的成果。

## 如何提交（Fork + Pull Request）

1. **Fork** 本仓库到你自己的 GitHub 账号（点右上角 Fork 按钮）；
2. **Clone** 你自己 Fork 出来的仓库到本地；
3. 在对应周目录下（如 `Week1/`）新建你的**个人文件夹**（用姓名拼音命名）；
4. 放入截图和说明（按各周 `README.md` 里的目录规范）；
5. `git add` → `git commit` → `git push`；
6. 在你自己的仓库页面发起 **Pull Request**。

> 详细步骤见各周目录下的说明，或群内《招新考核细则》。

## 目录结构

```
cquick-recruitment/
├── Week1/      # 环境搭建与 ROS2 入门
├── Week2/      # ROS2 pub/sub + 串口（待发布）
├── ...
└── README.md   # 本文件
```

## 目录规范

```
Week1/
└── <你的姓名拼音>/
    ├── 01_环境自检.png
    ├── 02_小乌龟.png
    ├── README.md
```

- 文件夹名 = 你的**姓名拼音**（如 `zhangsan`）；
- 截图按「序号_内容」命名，编号递增；
- 说明写在个人文件夹的 `README.md` 里。

## 考核相关

- **第 1 周考核细则**（任务、评分标准、防抄袭机制）→ 见仓库根目录《考核细则_第1周.md》；
- 截止时间见群通知；
- 有问题优先问 AI、看文档，解决不了在招新群里提问（附截图和报错信息）。
