## 任务 2：小乌龟
**节点(node)** 是独立运行的程序。
**话题(topic)** 是节点间传输数据的总线。
二者之间通过 **“发布”** 与 **“订阅”** 进行通信。

**Publisher** 节点发布话题，并将 **“消息(message)”** 发送至此话题。**Subscriber** 节点订阅此话题，从而收到到Publisher发送的消息。两节点之间必须使用完全相同的消息类型才能完成通信。同时两个节点之间无需知道对方的存在，只需约定好话题名称和数据格式就能配合，非常灵活。
