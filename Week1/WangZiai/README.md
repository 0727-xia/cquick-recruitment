## 任务 2：小乌龟

### 我对「节点」和「话题」的理解

1. **节点**是我们运行的程序；
2. **话题**是节点之间交换数据的通道；
3. 每个话题可以连接着多个节点，
   可将数据信息从一个节点中传递到其他节点中。
